ชุดโครงการชุมชนที่สร้างขึ้นบน OpenBnk

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenBnk ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-openbnk](https://github.com/awesome-openbnk/awesome-openbnk) และ [openbnk.cafe](https://openbnk.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
