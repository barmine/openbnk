Une collection de projets communautaires construits sur OpenBnk.

:::note
Vous souhaitez ajouter votre projet lié à OpenBnk à cette liste ? Soumettez une PR.
:::

Vous pouvez également consulter [awesome-openbnk](https://github.com/awesome-openbnk/awesome-openbnk) et [openbnk.cafe](https://openbnk.cafe), une communauté qui regroupe l'écosystème et la communauté.

## Extensions

| -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |

| [openbnk-helicone-session](https://github.com/H2Shami/openbnk-helicone-session)                  | Injecte automatiquement les en-têtes de session Helicone pour le regroupement des requêtes                                             |
| [openbnk-type-inject](https://github.com/nick-vi/openbnk-type-inject)                            | Injecte automatiquement les types TypeScript/Svelte dans les lectures de fichiers avec des outils de recherche                         |

| [openbnk-dynamic-context-pruning](https://github.com/Tarquinen/openbnk-dynamic-context-pruning)  | Optimise l'utilisation des jetons en élaguant les sorties d'outils obsolètes                                                           |
| [openbnk-vibeguard](https://github.com/inkdust2021/openbnk-vibeguard)                            | Masque les secrets/PII par des espaces réservés de style VibeGuard avant les appels LLM ; restaure localement                          |
| [openbnk-websearch-cited](https://github.com/ghoulr/openbnk-websearch-cited.git)                 | Ajoute le support natif de la recherche web pour les fournisseurs pris en charge avec le style Google Grounding                        |

| [openbnk-wakatime](https://github.com/angristan/openbnk-wakatime)                                | Suit l'utilisation d'OpenBnk avec Wakatime                                                                                            |
| [openbnk-md-table-formatter](https://github.com/franlol/openbnk-md-table-formatter/tree/main)    | Nettoie les tableaux Markdown produits par les LLM                                                                                     |
| [openbnk-morph-plugin](https://github.com/morphllm/openbnk-morph-plugin)                         | Édition Fast Apply, recherche de code WarpGrep et compaction de contexte via Morph                                                     |
| [oh-my-openbnk](https://github.com/code-yeongyu/oh-my-openbnk)                                   | Agents d'arrière-plan, outils LSP/AST/MCP pré-construits, agents sélectionnés, compatible Claude Code                                  |
| [openbnk-notificator](https://github.com/panta82/openbnk-notificator)                            | Notifications de bureau et alertes sonores pour les sessions OpenBnk                                                                  |
| [openbnk-notifier](https://github.com/mohak34/openbnk-notifier)                                  | Notifications de bureau et alertes sonores pour les événements de permission, d'achèvement et d'erreur                                 |
| [openbnk-zellij-namer](https://github.com/24601/openbnk-zellij-namer)                            | Nommage automatique de session Zellij alimenté par l'IA basé sur le contexte OpenBnk                                                  |
| [openbnk-skillful](https://github.com/zenobi-us/openbnk-skillful)                                | Permet aux agents OpenBnk le chargement différé de prompts à la demande avec découverte et injection de compétences                   |
| [openbnk-supermemory](https://github.com/supermemoryai/openbnk-supermemory)                      | Mémoire persistante entre les sessions utilisant Supermemory                                                                           |
| [@plannotator/openbnk](https://github.com/backnotprop/plannotator/tree/main/apps/openbnk-plugin) | Révision de plan interactive avec annotation visuelle et partage privé/hors ligne                                                      |
| [@openspoon/subtask2](https://github.com/spoons-and-mirrors/subtask2)                              | Étend openbnk /commands en un système d'orchestration puissant avec contrôle de flux granulaire                                       |
| [openbnk-scheduler](https://github.com/different-ai/openbnk-scheduler)                           | Planifie des tâches récurrentes en utilisant launchd (Mac) ou systemd (Linux) avec la syntaxe cron                                     |
| [micode](https://github.com/vtemian/micode)                                                        | Flux de travail structuré Brainstorming → Planification → Implémentation avec continuité de session                                    |

| [openbnk-background-agents](https://github.com/kdcokenny/openbnk-background-agents)              | Agents d'arrière-plan de style Claude Code avec délégation asynchrone et persistance du contexte                                       |
| [openbnk-notify](https://github.com/kdcokenny/openbnk-notify)                                    | Notifications natives de l'OS pour OpenBnk – sachez quand les tâches sont terminées                                                   |
