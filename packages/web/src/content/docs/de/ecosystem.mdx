---

Eine Sammlung von Community-Projekten, die auf OpenBnk basieren.

:::note
Möchten Sie Ihr OpenBnk-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-openbnk](https://github.com/awesome-openbnk/awesome-openbnk) und [openbnk.cafe](https://openbnk.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
