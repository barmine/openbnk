title: "Commands"
description: "Reference for the openbnk command line."
---

Every command accepts `--help` for its full flag list, for example `openbnk run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ openbnk run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: OpenBnk review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @openbnk/cli
      - run: openbnk run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ openbnk run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ openbnk run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ openbnk run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ openbnk run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ openbnk run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ openbnk run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ openbnk mini
```

Continue the last session.

```bash
$ openbnk mini --continue
```

Start with a model and an initial prompt.

```bash
$ openbnk mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ openbnk mini --help
```

## session

Manages sessions.

```bash
$ openbnk session list
```

Limit the list and print JSON.

```bash
$ openbnk session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ openbnk session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ openbnk session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ openbnk session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ openbnk session import session.json
```

Import into a specific directory.

```bash
$ openbnk session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ openbnk session --help
```

## auth

Manages AI providers and credentials.

```bash
$ openbnk auth list
```

List them as JSON.

```bash
$ openbnk auth list --format json
```

Log in to a provider.

```bash
$ openbnk auth login anthropic
```

Log in with a specific authentication method.

```bash
$ openbnk auth login anthropic --method key
```

Log out of a saved account.

```bash
$ openbnk auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ openbnk auth switch anthropic work
```

View all subcommands and flags.

```bash
$ openbnk auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ openbnk mcp list
```

Add a remote server.

```bash
$ openbnk mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ openbnk mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ openbnk mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ openbnk mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ openbnk mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ openbnk mcp logout sentry
```

View all subcommands and flags.

```bash
$ openbnk mcp --help
```

## plugin

Manages plugins.

```bash
$ openbnk plugin list
```

Include built-in server plugins.

```bash
$ openbnk plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ openbnk plugin add @example/openbnk-tui
```

Check package plugins for updates.

```bash
$ openbnk plugin check
```

Update package plugins.

```bash
$ openbnk plugin update
```

Remove a plugin from global configuration.

```bash
$ openbnk plugin remove @example/openbnk-tui
```

View all subcommands and flags.

```bash
$ openbnk plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ openbnk serve
```

Bind to all interfaces on a fixed port.

```bash
$ openbnk serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ openbnk serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ openbnk serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ openbnk pair
```

Use an external URL in the links.

```bash
$ openbnk pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ openbnk pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ openbnk pair --remote --yes
```

View all subcommands and flags.

```bash
$ openbnk pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ openbnk service start
```

Restart it.

```bash
$ openbnk service restart
```

Show its status.

```bash
$ openbnk service status
```

Stop it.

```bash
$ openbnk service stop
```

Read a setting.

```bash
$ openbnk service get hostname
```

Set a setting.

```bash
$ openbnk service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ openbnk service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ openbnk service set env OPENBNK_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ openbnk service unset hostname
```

View all subcommands and flags.

```bash
$ openbnk service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ openbnk reload
```

## api

Makes a request to the running server.

```bash
$ openbnk api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ openbnk api session.list --param limit=10
```

Send a JSON body.

```bash
$ openbnk api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ openbnk api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ openbnk api --help
```

## upgrade

Upgrades OpenBnk to the latest or a specific version. Alias: `update`.

```bash
$ openbnk upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ openbnk upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ openbnk upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls OpenBnk. Session data, configuration, and
state are not removed.

```bash
$ openbnk uninstall
```

Preview what would be removed.

```bash
$ openbnk uninstall --dry-run
```

View all subcommands and flags.

```bash
$ openbnk uninstall --help
```
