[Pi](https://pi.dev) includes OpenBnk providers for pay-as-you-go and Go. It picks the right API for each model, so
every Console model works.

| Provider      | Plan          |
| ------------- | ------------- |
| `openbnk`    | Pay-as-you-go |
| `openbnk-go` | Go            |

## Configure

Both providers read the key from `OPENBNK_API_KEY`. Create a [personal API key](/console/harnesses#get-an-api-key).

```bash
export OPENBNK_API_KEY="oc_sk_..."
pi --model openbnk/claude-sonnet-5-5
```

You can also run `/login` in Pi and select the provider. Pi stores the key in `~/.pi/agent/auth.json`.

```text
/login openbnk
```

## Go

Use the `openbnk-go` provider with a key from a workspace with a [Go](/console/go) subscription.

```bash
pi --model openbnk-go/kimi-k3
```

## Models

Select a model as `<provider>/<model-id>`, using IDs from the [Console](/console/models#endpoints) or
[Go](/console/go#endpoints) table. List the models Pi knows about with `--list-models`.

```bash
pi --list-models openbnk-go
```

Set a default in `~/.pi/agent/settings.json`, or press `Ctrl+S` in the `/model` picker.

```json title="~/.pi/agent/settings.json"
{
  "defaultProvider": "openbnk-go",
  "defaultModel": "kimi-k3"
}
```

Run `pi update --models` when a new Console model doesn't appear yet.

## Console MCP

Pi v0.99.0 and later support MCP. Add the [Console MCP](/console/harnesses#console-mcp) server, then sign in from the
browser.

```bash
pi mcp add openbnk-console --url https://openbnk.local/console/mcp
pi mcp login openbnk-console
```
